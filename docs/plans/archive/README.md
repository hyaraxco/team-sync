# Historical Plans and Designs

Dokumen di folder ini menyimpan riwayat desain, audit, rencana, dan laporan
implementasi. **Diarsipkan tidak selalu berarti selesai.** Beberapa dokumen
merupakan draft/superseded atau masih memiliki checklist tanpa bukti penutupan.

- Tanggal pada nama file adalah konteks historis, bukan versi kontrak API.
- Angka tes di dalamnya adalah hasil yang dicatat saat itu, bukan hasil tes terbaru.
- Jangan menjalankan langkah migrasi, seeding, deployment, atau perintah lama
  tanpa memeriksa kode dan konfigurasi saat ini.
- Pertahankan bukti TOPSIS, payroll, permission, dan QA untuk penelusuran keputusan.

Panduan aktif dan roadmap ada di [indeks dokumentasi](../../README.md).
